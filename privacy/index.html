Политика конфиденциальности

Приложение «ИИ-садовник» (пакет ru.aigardener.ai_gardener).

Дата актуализации: 18.11.2026.

1. Кто обрабатывает данные

Учётной записи в приложении нет. По вопросам обработки данных напишите на valera7623@gmail.com.

2. Какие данные обрабатываются

Фото растения вы делаете камерой или выбираете из галереи. Если интернет есть и вы нажали «Распознать», сжатое фото отправляется на сервер приложения https://aegisai.fun. Сервер передаёт его в Yandex Cloud, чтобы вернуть текстовую подсказку. Без интернета фото остаётся на телефоне: его оценивает модель в приложении и наружу оно не уходит.

История хранит на телефоне копию снимка, название, описание и рекомендации. Свайп влево удаляет запись и эту копию. Исходный файл в галерее не удаляется.

На телефоне также сохраняются тема, климатическая зона и включённые вами напоминания календаря. Напоминание приходит около 9:00 с самого телефона, не с сервера.

3. Зачем нужны разрешения

Камера нужна, чтобы снять растение. Уведомления нужны только для напоминаний календаря, которые вы включаете сами. После перезагрузки телефона приложение восстанавливает уже включённые напоминания. Интернет нужен для облачной подсказки. Справочник, история и календарь открываются без сети.

4. Передача третьим лицам

Рекламных и аналитических сервисов в приложении нет. Фото передаётся дальше только в момент онлайн-распознавания: на сервер приложения и затем в Yandex Cloud для текста ответа. Галерея, история и настройки сами по себе на сервер не отправляются. Резервное копирование данных приложения отключено.

5. Срок хранения и удаление

История и настройки хранятся на телефоне, пока вы их не удалите или не удалите приложение. Удаление приложения стирает его данные с устройства. Срок хранения фото на стороне Yandex Cloud определяется правилами этого сервиса.

6. Ограничение

Подсказка по фото не является диагнозом, заключением агронома и основанием для обработки растения. Сверьте её с листом. При сомнении не обрабатывайте растение наугад.
